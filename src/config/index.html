General

How asar launches and where you can reach it.

    Feel

    Instant UISwitches on Discord's own reduced-motion mode, so modals, popouts and channel switches don't animate.
    Turn off blurRemoves background blur, one of the most expensive effects for your GPU. Looks almost the same.
    High priorityWindows gives all of Discord's processes CPU time before other apps. Can make games you're playing or streaming stutter.

    Preset

    Optimizations

    Compile cacheCaches compiled JavaScript so Discord's core loads faster after the first launch.
    DOM optimizerExperimental. Delays removing some elements while Discord re-renders. Leave off if channels load slowly.
    Space separated. Added on top of the preset.

    Privacy

    Network requests asar blocks before they leave your machine.

    Block trackingBlocks Discord analytics (science, metrics) and Sentry error reporting.
    Hide typing indicatorOthers won't see “is typing…” when you type.

    Repair

    Repair cachesClears Discord's graphics, code and download caches the next time Discord starts. A common fix for slow loading and glitches. Images download again once.

    Restore stock DiscordPuts back Discord's original app.asar and restarts. asar is kept as app.asar.asar-fork.
